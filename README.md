# EV Charging Station API

Это мой практический проект — полноценный API для управления электрозаправочными станциями, написанный на FastAPI и SQLite.

## Что умеет этот проект (Features)

* **Управление станциями (CRUD):** Можно создавать новые заправки, удалять их, обновлять данные и смотреть список доступных станций.
* **Симуляция зарядки без лагов:** Процесс зарядки автомобиля занимает время. Я реализовал его через `async/await` и `asyncio.sleep(3)`. Благодаря этому несколько машин могут "заряжаться" одновременно в одном потоке, и сервер не зависает.
* **Решение проблемы с блокировкой базы:** SQLite — это простой файл, и когда в него идет одновременная запись, он выдает ошибку. Я настроил базу данных (включил режим WAL и увеличил timeout), чтобы избежать этих блокировок сервера.
* **Обработка ошибок:** Настроил кастомные HTTP-ошибки в файле `helpers.py` и `main.py`, чтобы если станции нет в базе, пользователь получал четкий ответ 404, а не падение сервера с 500 ошибкой.

## Стек технологий (Tech Stack)

* Python 3.11+
* FastAPI / Uvicorn
* SQLite (с настройкой потокобезопасности)
* Git

## Как запустить проект локально

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com
   cd ev-charging-station-api
   ```
2. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустить сервер:
   ```bash
   uvicorn main:app --reload
   ```
